# Navigation & resource UX benchmark

**Purpose:** Study peer sites so AfterCare can be resource-rich, kid-navigable, and accurate — without copying their copy, logos, or assets.  
**Date:** 2026-11-21 · **Scope:** California foster youth ages 14–26

## What each site does well

| Site | Patterns that work |
| --- | --- |
| **FosterClub Help Hub** ([fosterclub.com/helphub](https://www.fosterclub.com/helphub)) | State picker first; youth “Explainers” (step guides); emergency block (911 / 988 / trafficking) always visible; chat + phone for “not sure.” |
| **John Burton Advocates for Youth** ([jbay.org/resources](https://jbay.org/resources/)) | Filterable resource library; **county program rosters** (ILP, FUP/FYI, AB 12 re-entry); “Last updated” dates on every piece. |
| **California Youth Connection** ([calyouthconn.org](https://calyouthconn.org/)) | Youth-led voice; policy → rights framing; clear peer advocacy entry. |
| **Children’s Law Center of CA** ([clccal.org](https://www.clccal.org/)) | Role clarity (court-appointed counsel); county coverage; rights education without pretending to be a hotline. |
| **CDSS Foster Care** ([cdss.ca.gov](https://www.cdss.ca.gov/inforesources/foster-care)) | Official county contacts for EFC / THP / ILP; Bill of Rights; program definitions youth can trust. |
| **Think of Us** ([thinkof.us](https://www.thinkof.us/)) | Lived-experience research hub; digital tools framed as peer-built, not casework. |
| **Juvenile Law Center** ([jlc.org](https://jlc.org/)) | Issue libraries (records, aging out); plain briefs with legal sources. |
| **211 / findhelp.org** | Taxonomy by need; local / ZIP search; “open now”; multi-service referrals without jargon. |
| **Trevor Project** | Crisis CTA above the fold; call / text / chat equal weight; audience specificity (LGBTQ+ youth). |
| **Crisis Text Line** | One action (“text HOME to 741741”); zero friction. |
| **Covenant House** | Shelter / housing path clear; 24/7 youth phone; location honesty. |
| **StandUp For Kids** | Local chapter model; street outreach + drop-in clarity. |
| **GoFundMe.org / charity:water** | Donor trust UX (progress, proof); we adapt **transparency + proof**, not fundraising copy. |
| **Benefits.gov / GetCalFresh / mRelief** | Screener questions → personalized checklist; short forms; eligibility in plain language. |
| **gov.uk** | Task-based navigation (“Do this…”); 6–8th grade reading; one job per page; service-standard honesty. |

## Patterns AfterCare adopts (and why)

1. **Task language, not org jargon** (gov.uk + FosterClub) — “I need a place to sleep,” not “Housing continuum of care.”
2. **2 taps to a phone or official link** (Crisis Text + Trevor) — home → task or search → listing.
3. **State/county first, then topic** (FosterClub + JBAY + CDSS) — California default; county ZIP kept in the browser only.
4. **Always-on crisis strip** (FosterClub emergency + Trevor) — already shipped; keep expanding.
5. **Verified + last-checked + source URL** (JBAY “Last updated” + findhelp honesty) — never invent orgs or numbers.
6. **County ILP / EFC contacts from CDSS** (official roster) — one listing per county where CDSS publishes a contact.
7. **Benefits screener → checklist** (GetCalFresh / mRelief / Benefits.gov) — extend `/find` + directory filters.
8. **Quick exit** (DV / gov safety pattern) — one-tap leave for youth in unsafe places.
9. **Search with synonyms** (findhelp taxonomy) — “kicked out” → shelter; “food” → CalFresh; “ID” → documents.
10. **Ask that cites sources or admits unknown** (gov.uk honesty) — chat points at verified listings / guides or 211 / 988.
11. **Report outdated info** (FosterClub broken-link email) — mailto on every listing.
12. **Spanish-ready structure** (OFCO / LifeLine Spanish cues) — `lang` hooks and bilingual crisis labels first; full ES copy later.

## What we refuse

- Copying logos, brand systems, or marketing copy.
- Claiming partnership with any org we only list.
- Fabricating phone numbers, stats, or “verified” without an official page check.
- Collecting ZIP / county on a server (browser-only).
